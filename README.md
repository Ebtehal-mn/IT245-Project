👥 Recent Profile Visitors System

This is a project for IT245 – Data Structure at the SEU.

Project Overview:
The Recent Profile Visitors System is a Java-based application designed to track and manage the latest profile views in a social media context. The system efficiently records visitor activity, filters duplicate interactions, and maintains chronological ordering using two different algorithmic data structure approaches (Stack and HashMap).

To support teamwork and maintain a transparent GitHub commit history, the project was organized into modular classes during development.
